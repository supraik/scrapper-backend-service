# scrapper-backend-service

A production-grade backend service that tracks product prices from a dynamic e-commerce site. It scrapes prices on a scheduled cron cycle, persists historical data in PostgreSQL, and exposes a REST API for users to subscribe to products and view price history.

---

## Architecture Overview

```
┌─────────────────────────────────────────────────────────┐
│                      app.js (Express)                   │
│         REST API  ──────────────  Cron Scheduler        │
└────────────┬────────────────────────────┬───────────────┘
             │                            │
     routes/route.js              cron/index.js
             │                            │
  controllers/allControllers.js   cron/scraper.js  ←── Puppeteer
             │                            │
        models/                    cron/db_interactions.js
   productModel.js                        │
   historyModel.js  ←────────────────────┘
             │
        db/index.js (PostgreSQL via pg Pool)
```

---

## Features

- **Automated price scraping** — Puppeteer-based scraper runs every hour via `node-cron`, only for products with at least one active subscriber
- **Reliable extraction** — Two-phase interaction model (hover → reveal button → checkpoint state machine) handles dynamic price loading
- **Per-product retry logic** — Up to 5 retries per product, each in an isolated browser tab; failures are recorded, not silently dropped
- **Parallel batch processing** — Processes 3 products concurrently to balance speed and memory usage
- **Price history** — Full timestamped JSONB history stored per product in PostgreSQL; auto-cleaned when subscriber count reaches zero
- **REST API** — Search products, subscribe/unsubscribe, view dashboard, and fetch price history charts
- **Stateless auth** — Auto-generated user ID issued on first request, returned via `userid` response header

## Database Schema

```sql
-- Products catalog
CREATE TABLE products (
  product_id       SERIAL PRIMARY KEY,
  name             VARCHAR(255) NOT NULL,
  brand            VARCHAR(255),
  category         VARCHAR(255),
  users_subscribed INT DEFAULT 0
);

-- User → Product subscription mapping
CREATE TABLE user_products (
  user_id    INT NOT NULL,
  product_id INT NOT NULL REFERENCES products(product_id) ON DELETE CASCADE,
  PRIMARY KEY (user_id, product_id)
);

-- Price history per product (JSONB array, one entry per scrape)
CREATE TABLE history (
  product_id INT PRIMARY KEY REFERENCES products(product_id) ON DELETE CASCADE,
  data       JSONB NOT NULL
);
```

## Setup & Installation

### Prerequisites
- Node.js v18+
- PostgreSQL database
- Chromium (installed automatically by Puppeteer)

### 1. Install dependencies
```bash
npm install
```

### 2. Configure environment
Create a `.env` file in the project root:
```env
DATABASE_URL=postgresql://user:password@host:5432/dbname
PORT=8000
```

### 3. Create database tables
```bash
psql $DATABASE_URL -f init/make_tables.sql
```

### 4. Seed the product catalog
```bash
# Step 1 — Fetch all 1,000 products from the catalog API
node init/fetch_all_products.js

# Step 2 — Insert them into PostgreSQL (chunks of 50)
node init/seed.js
```

### 5. Start the server
```bash
node app.js
```

The server starts on port `8000` and immediately fires the first scrape cycle on boot, then runs every hour.

## API Reference

All routes require an `authorization` header (user ID). If omitted, one is auto-generated and returned in the `userid` response header.

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/api/health` | Health check |
| `GET` | `/search?q=&limit=&offset=` | Full-text search across name, brand, category |
| `GET` | `/add?productId=` | Subscribe to a product |
| `GET` | `/remove?productId=` | Unsubscribe from a product |
| `GET` | `/dashboard` | All subscribed products with latest price + stock |
| `GET` | `/history?productId=` | Full price history array for a product |

### Example — Search
```bash
curl "http://localhost:8000/search?q=laptop&limit=5" \
  -H "authorization: 12345"
```

### Example — Subscribe
```bash
curl "http://localhost:8000/add?productId=42" \
  -H "authorization: 12345"
```

## How the Scraper Works

The scraper (`cron/scraper.js`) uses Puppeteer to interact with a dynamic product page that hides prices behind a user-triggered reveal mechanism.

### Phase 1 — Hover to activate
The "Reveal Price" button starts disabled. The scraper hovers over `.price-substatus` to trigger the site's JS and enable it, suppressing cookie overlays on every attempt.

### Phase 2 — Click + checkpoint state machine
After clicking the button, the scraper enters a 15-round loop reading the DOM state each round:

| State | Action |
|---|---|
| `price-success` | Extract price → done |
| `loading` (spinner / `aria-busy`) | Wait 3s → next round |
| `price-error` | Click "Try again" → wait 3s |
| `reveal-active` (click missed) | Re-click button → wait 3s |
| `unknown` | Wait 3s → next round |

### Price Parser
The site renders prices in multiple formats across pages. The `parsePrice()` function handles all of them:

| Format | Example |
|---|---|
| Standard comma-thousands | `₹21,626` |
| Space-separated thousands | `₹12 449` |
| Full-width unicode digits | `₹４２,１４４` |
| Indian lakh format | `₹1,26,960` |
| Trailing paise | `Rs. 50,707.00` |
| EU/glitchy (site bug) | `₹50.707,00` |
| Char-split with zero-width spaces | `₹​1​3​,​1​8​4` |
